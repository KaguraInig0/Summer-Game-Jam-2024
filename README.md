# Vista

An Oregon Trail-inspired road trip game set along the coast and countryside 
of a loosely fictional California.

Players travel from town to town visiting their grandfather in San Francisco, 
exploring walkable 2.5D environments, meeting characters, and surviving 
humorous random encounters along the way.

Selected for presentation at the Summer Game Jam 2024.

## Gameplay
- Oregon Trail-style travel interface
- Walkable 2.5D towns with pixel art in a 3D world
- Random mid-trip encounters
- Party happiness and supplies management

## Installation
1. Fork this project by clicking the Fork icon at the top right
2. Clone the forked repo: `git clone <git_url>`
3. Open Terminal and navigate to the `Summer-Game-Jam-2024` directory

## Github Guide

**Syncing with Repository**
1. In your forked repo, click Sync Fork then Update Branch
2. `git pull` — pulls the latest update
3. `git merge` — merge if no conflicts

**Pushing Updates**
1. `git add .`
2. `git commit -m "<message>"` — describe what you changed
3. `git push -u origin main`
